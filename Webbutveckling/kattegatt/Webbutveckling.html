Webbutveckling på Kattegattgymnasiet

På Kattegattgymnasiet får du lära dig att skapa moderna, användarvänliga och interaktiva webbplatser. Du arbetar med hela processen, från den första idén och designen till färdig kod och publicering. Under utbildningen kombinerar du kreativt skapande med programmering, problemlösning och förståelse för hur webben fungerar.

Vad får du lära dig?

Från design till webbplats

Du lär dig att bygga webbplatser med HTML, CSS och JavaScript. HTML ger sidan struktur, CSS skapar färg och layout och JavaScript gör sidan interaktiv. Du får också arbeta med responsiv design så att webbplatser fungerar på både datorer, surfplattor och mobiler.


En viktig del av webbutveckling är att skapa sidor som är tydliga och enkla att använda. Därför får du träna på användarupplevelse, tillgänglighet, färgval och typografi samtidigt som du utvecklar din tekniska förståelse.

Det här kan du arbeta med

HTML och CSS
Bygg upp webbsidor med tydlig struktur och skapa layouter som ser bra ut på alla skärmar.


JavaScript
Lägg till interaktivitet, formulär, animationer och funktioner som gör webbplatser levande.


Design och användarupplevelse
Planera färger, bilder, navigation och innehåll så att webbplatsen blir lätt att förstå och använda.


Webbserverprogrammering
Lär dig hur webbplatser kan kommunicera med servrar och databaser för att hantera dynamiskt innehåll.


Egna webbprojekt
Skapa exempelvis en portfolio, en informationssida, en blogg eller en interaktiv tjänst från idé till färdig webbplats.


Efter gymnasiet
Kunskaperna kan leda vidare till studier eller arbete som webbutvecklare, frontendutvecklare, webbdesigner, UX-designer eller digital kommunikatör.
